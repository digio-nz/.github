# digio-nz/.github

Org-wide default issue and pull request templates for digio-nz.
GitHub uses these for any repo that has no templates of its own.

Source: [digio-michelin `templates/github/`](https://github.com/digio-nz/digio-michelin/tree/23dffeea7c55461c8b24c9ca39b8ab2e4057c2dd/templates/github) at `23dffeea7c55461c8b24c9ca39b8ab2e4057c2dd`.
